# 프론트엔드 2주차 작업 정리

## 1. 작업 목적

이번 주차에는 프론트엔드를 백엔드 WebSocket stream과 연결하고, 수신한 DOA 추론 결과를 대시보드 형태로 시각화했다.

초기 화면은 placeholder와 raw JSON 중심이었기 때문에 실제 시연용 화면으로 보기 어려웠다. 따라서 다음 작업을 진행했다.

- `/predict` 호출 제거
- `/health` 기반 서버 연결 확인
- WebSocket 메시지 수신 및 history 저장
- 추론 이벤트 정규화 함수 추가
- Polar, Spectrum, Waterfall chart 구현
- Summary panel 추가
- Stop 버튼을 Pause Display 기능으로 변경
- Vite 기본 전역 스타일 제거 및 대시보드 레이아웃 정리

## 2. 백엔드 연결 변경

### `frontend/.env`

변경 전에는 프론트에서 백엔드 주소를 직접 사용했다.

```env
VITE_API_BASE_URL=http://127.0.0.1:8000
```

변경 후에는 Vite proxy를 사용한다.

```env
VITE_API_BASE_URL=/api
VITE_WS_URL=ws://127.0.0.1:8000/ws
```

### `frontend/vite.config.js`

`/api` 요청을 백엔드로 proxy하도록 설정했다.

```text
/api/health -> http://127.0.0.1:8000/health
```

이렇게 한 이유는 브라우저에서 직접 `http://127.0.0.1:8000`으로 요청할 때 발생할 수 있는 CORS 문제를 피하기 위해서다.

## 3. 변경한 함수 기준 정리

## 3.1 `useWebSocket(url)`

파일:

```text
frontend/src/hooks/useWebSocket.js
```

역할:

- WebSocket 연결 생성
- 연결 상태 관리
- 최신 메시지 저장
- 최근 메시지 history 저장
- 마지막 메시지 수신 시각 저장
- 연결 에러 저장
- 최근 추론 결과 localStorage 캐시 저장
- 새로고침 시 캐시된 최신 결과와 history 복구
- pause 상태에서는 화면 갱신을 멈추고 캐시만 계속 갱신

반환값:

```js
return {
  status,
  message,
  messageHistory,
  lastMessageAt,
  error,
};
```

주요 상태:

- `status`: `connected`, `disconnected`, `error`
- `message`: 가장 최근 WebSocket 메시지
- `messageHistory`: 최근 WebSocket 메시지 목록
- `lastMessageAt`: 마지막 수신 시간
- `error`: WebSocket 연결 에러

추가한 이유:

Waterfall chart는 한 프레임만으로 그릴 수 없고, 여러 프레임의 spectrum history가 필요하다. 그래서 `messageHistory`를 추가했다.

또한 WebSocket이 연결되기 전이나 브라우저를 새로고침한 직후에도 마지막 대시보드 상태를 복구할 수 있도록 localStorage 캐시를 추가했다.

현재 캐시 정책:

```text
latest: 가장 최근 추론 결과 1개
history: 최근 추론 결과 최대 50개
```

화면 표시 우선순위:

```text
새 WebSocket 메시지 수신
-> 즉시 React state 업데이트
-> 동시에 localStorage cache 갱신
```

즉, 캐시는 화면 표시를 지연시키는 대기열이 아니라 최근 수신 기록을 남기는 로그/복구용 저장소다.

Pause Display 동작:

```text
Pause Display ON
-> WebSocket 연결 유지
-> 새 메시지는 localStorage cache와 내부 ref에 저장
-> React 화면 state는 갱신하지 않음

Pause Display OFF
-> pause 중 받은 최신 메시지와 history를 화면 state로 동기화
```

이 방식은 백엔드 stream을 멈추는 것이 아니라 프론트 화면만 고정하는 기능이다.

파일:

```text
frontend/src/hooks/useWebSocket.js
```

역할:


localStorage 용량 제한이나 브라우저 설정 때문에 저장에 실패해도 실시간 화면 갱신은 계속되어야 하므로, 저장 실패는 조용히 무시한다.

## 3.1.3 `getEventKey(message)`

파일:

```text
frontend/src/hooks/useWebSocket.js
```

역할:

중복 이벤트를 판별하기 위한 key를 구한다.

현재는 정식 이벤트 구조에서 제공될 수 있는 `event_id`를 우선 사용한다.

```js
return inference.eventId;
```

현재 mock stream에는 `event_id`가 없기 때문에 중복 제거가 강하게 적용되지는 않는다. 향후 백엔드가 `event_id`를 제공하면 같은 이벤트가 두 번 history에 쌓이는 것을 막을 수 있다.

## 3.1.4 `appendMessage(history, nextMessage)`

파일:

```text
frontend/src/hooks/useWebSocket.js
```

역할:

새 WebSocket 메시지를 history에 추가하고, 최근 50개만 유지한다.

동작:

```text
1. event_id가 있고 이미 같은 event_id가 history에 있으면 추가하지 않음
2. 중복이 아니면 history 끝에 추가
3. 마지막 50개만 남김
```

이 방식은 최신 데이터를 바로 보여주면서도 오래된 기록이 무한히 쌓이지 않도록 한다.

## 3.2 `normalizeInferenceEvent(event)`

파일:

```text
frontend/src/utils/inferenceEvent.js
```

역할:

백엔드에서 오는 이벤트 구조를 프론트엔드 차트가 쓰기 쉬운 공통 구조로 변환한다.

현재 백엔드 mock event:

```json
{
  "type": "stream_inference_result",
  "data": {
    "estimated_k": 5,
    "doas_deg": [-9, -1, 28, 45, 48],
    "confidence": 0.93,
    "spectrum": []
  }
}
```

향후 문서 기준 정식 event:

```json
{
  "event_id": "...",
  "k_estimate": 3,
  "doa_deg": [-31.5, 4.0, 42.5],
  "peak_scores": [0.94, 0.88, 0.76],
  "spectrum": {
    "grid_start": -90,
    "grid_end": 90,
    "grid_size": 360,
    "values": []
  }
}
```

정규화 후 프론트에서 사용하는 구조:

```js
{
  eventId,
  type,
  timestamp,
  sensorId,
  kEstimate,
  doas,
  peakScores,
  confidence,
  spectrum,
  sampleIndex,
  inputFile,
  streaming,
}
```

추가한 이유:

백엔드 mock 필드명은 `estimated_k`, `doas_deg`, `spectrum`이고, 문서의 정식 구조는 `k_estimate`, `doa_deg`, `spectrum.values`이다. 차트 컴포넌트가 이 차이를 직접 알게 하면 유지보수가 어려워지므로 중간 정규화 함수를 만들었다.

역할:

## 5. 백엔드 확인 내용

백엔드 WebSocket endpoint는 정상 동작했다.

```text
ping -> pong
```

하지만 처음에는 stream message가 오지 않았다. 원인은 백엔드 stream이 다음 파일에 의존하기 때문이었다.

```python
STREAM_H5_PATH = "train_mini_1bit.h5"
```

필요한 파일 위치:

```text
LC_PSN/train_mini_1bit.h5
```

파일을 추가한 뒤에는 백엔드 서버를 재시작해야 한다.

정상 실행 로그:

```text
[STREAM] Loaded train_mini_1bit.h5
[STREAM] X shape = ...
[STREAM] Sent sample index 0
```
