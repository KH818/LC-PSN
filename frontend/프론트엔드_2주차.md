# 프론트엔드 2주차 작업 정리

## 1. 작업 개요

이번 작업에서는 기존 placeholder 형태의 프론트엔드 화면을 실제 백엔드 WebSocket 데이터와 연결되는 실시간 DOA 대시보드 형태로 정리했다.

주요 목표는 다음과 같았다.

- 백엔드 서버와 프론트엔드 연결 상태 확인
- WebSocket으로 수신한 추론 결과를 React 상태로 관리
- 수신 데이터를 그래프 형태로 시각화
- 기존 임시 UI를 대시보드 형태로 개선
- 현재 mock 이벤트 구조와 향후 정식 이벤트 구조를 모두 처리할 수 있는 데이터 어댑터 추가

## 2. 백엔드 연결 방식

현재 프론트엔드 환경 변수는 다음과 같다.

```env
VITE_API_BASE_URL=/api
VITE_WS_URL=ws://127.0.0.1:8000/ws
```

REST API는 Vite proxy를 통해 백엔드로 전달한다.

```text
/api/health -> http://127.0.0.1:8000/health
```

실시간 추론 결과는 WebSocket으로 직접 수신한다.

```text
ws://127.0.0.1:8000/ws
```

기존 프론트엔드는 `/predict`를 호출했지만, 최신 백엔드에서는 `/predict`가 제거되고 WebSocket 기반 자동 스트리밍 구조로 바뀌었다. 따라서 프론트엔드에서도 `/predict` 호출을 제거하고 `/health` 확인 및 WebSocket 수신 방식으로 수정했다.

## 3. 데이터 흐름

프론트엔드의 데이터 흐름은 다음과 같다.

1. `useWebSocket` 훅에서 백엔드 WebSocket에 연결한다.
2. 메시지가 들어오면 JSON으로 파싱한다.
3. 최신 메시지는 `message` 상태에 저장한다.
4. 최근 메시지들은 `messageHistory`에 누적한다.
5. `normalizeInferenceEvent`에서 백엔드 이벤트를 프론트엔드용 공통 구조로 변환한다.
6. 변환된 데이터를 summary panel과 chart component에서 사용한다.

이 구조를 통해 현재 mock 이벤트뿐 아니라 향후 정식 이벤트 구조도 같은 UI에서 처리할 수 있도록 했다.

## 4. 지원하는 이벤트 구조

현재 백엔드 mock stream 이벤트는 다음과 같은 형태다.

```json
{
  "type": "stream_inference_result",
  "data": {
    "estimated_k": 5,
    "doas_deg": [-9, -1, 28, 45, 48],
    "confidence": 0.93,
    "spectrum": [0.01, 0.02, 0.9]
  }
}
```

`졸업작품.md`에서 정리한 향후 정식 이벤트 구조도 처리할 수 있도록 준비했다.

```json
{
  "event_id": "...",
  "k_estimate": 3,
  "doa_deg": [-31.5, 4.0, 42.5],
  "peak_scores": [0.94, 0.88, 0.76],
  "spectrum": {
    "grid_start": -90,
    "grid_end": 90,
    "grid_size": 360,
    "values": []
  }
}
```

이를 위해 `frontend/src/utils/inferenceEvent.js` 파일을 추가했다.

## 5. UI 개선 내용

기존 화면은 raw JSON과 placeholder 영역이 그대로 노출되어 대시보드처럼 보기 어려웠다. 이를 다음과 같이 개선했다.

- 상단 header 정리
- 좌측 connection status panel 정리
- server check control 추가
- summary metric panel 추가
- DOA polar chart 추가
- spectrum line chart 추가
- waterfall history chart 추가
- raw JSON 출력 카드 제거

### Summary Panel

새 summary panel에서는 다음 정보를 보여준다.

- K estimate
- Confidence
- DOA angles
- Spectrum bins

### Chart

외부 차트 라이브러리를 추가하지 않고 SVG와 CSS만 사용하여 그래프를 구현했다.

- `PolarChart`: 추정 DOA 각도를 반원 polar chart로 표시
- `SpectrumChart`: spectrum 배열을 line chart로 표시
- `WaterfallChart`: 최근 spectrum history를 heatmap 형태로 표시

DOA source가 많을 때 라벨이 겹치는 문제가 있어서, source 개수가 많으면 각 ray 옆 라벨을 숨기고 chart header에 각도 목록을 표시하도록 수정했다.

## 6. 스타일 정리

기존 `index.css`에는 Vite 기본 템플릿 스타일이 남아 있었다.

특히 다음 스타일들이 대시보드 레이아웃을 망가뜨렸다.

- `#root` 고정 폭
- 전체 text-align center
- 전역 h1 대형 스타일
- light/dark 템플릿 변수

이를 제거하고 대시보드 전용 전역 스타일로 정리했다.

주요 변경 파일:

```text
frontend/src/index.css
frontend/src/App.css
```

## 7. 백엔드 확인 내용

백엔드 WebSocket endpoint 자체는 정상 동작했다.

```text
ping -> pong
```

하지만 처음에는 3초마다 stream message가 오지 않았다. 원인은 백엔드 자동 스트리밍이 다음 파일에 의존하기 때문이었다.

```python
STREAM_H5_PATH = "train_mini_1bit.h5"
```

필요한 파일 위치:

```text
LC_PSN/train_mini_1bit.h5
```

`.h5` 파일을 추가한 뒤에는 백엔드 서버를 재시작해야 background stream task가 파일을 다시 로드한다.

정상 실행 시 백엔드 콘솔에는 다음과 같은 로그가 나와야 한다.

```text
[STREAM] Loaded train_mini_1bit.h5
[STREAM] X shape = ...
[STREAM] Sent sample index 0
```
