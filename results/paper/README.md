# Paper result tables

These CSVs are the 8-degree-minimum-separation exports associated with the manuscript. `unified_all_8deg_summary.csv` is the source for the main comparison table. The SNR and snapshot files preserve per-model/per-seed rows; `unified_sep8_seed_avg_8deg.csv` contains their three-seed aggregation. `confusion_counts.csv` contains the LCPSN source-count confusion totals.

These files are reference artifacts. New evaluation runs are written under `evaluation/results/` with the prefix selected by `--out-prefix`.
