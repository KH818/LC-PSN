Before publishing, the authors should:

1. confirm ownership and provenance of LCPSN and every file under `baselines/`;
2. check whether any comparison code was copied or adapted from another repository and preserve its copyright and license notices;
3. select a license for the authors' own code, such as BSD-3-Clause, MIT, or Apache-2.0;
4. replace this file with the chosen `LICENSE` and update `THIRD_PARTY.md`.
